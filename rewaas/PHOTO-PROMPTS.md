# REWAAS — Photo Generation List

Har photo ko ChatGPT mein banakar **bataye gaye file naam se** `rewaas/public/photos/` folder mein save karein (JPG ya PNG dono chalega), phir commit + push karein.
Ek photo ke liye ek naya prompt. Agar photo pasand na aaye to dobara generate karein.

## Style rules (har prompt ke saath yeh line jodna)
> Style: premium Indian luxury fashion editorial photography, natural soft daylight, warm ivory and deep wine-red colour palette with antique gold accents, elegant and minimal composition, sharp focus on fabric texture and embroidery, photorealistic, high-end magazine quality. No text, no logos, no watermark.

Models: graceful Indian women (age 22–35), natural makeup, no exaggerated poses. Faces can be partly turned or cropped for an editorial feel.
